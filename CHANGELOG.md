# Changelog

All notable changes are documented here.

## 1.0.0 — 2026-08-16

- Added local browser inspection for JPEG, PNG, WebP, DOCX, XLSX, PPTX, and PDF.
- Added image metadata and Office Open XML safe-copy generation.
- Added post-sanitization re-scan and content-fingerprint verification.
- Added optional official C2PA Web SDK validation on user request.
- Added zero-dependency Node.js CLI with JSON, Markdown, and CI threshold output.
- Added synthetic geotagged image, private résumé, and active PDF demos.
- Added bounded ZIP parser protections, including streaming expansion limits that reject forged size declarations.
- Added bounded PNG compressed-text, PDF Flate-stream, and WebP provenance inspection.
- Added test suite, PWA shell, GitHub Pages workflow, citation metadata, and reproducible release packaging.

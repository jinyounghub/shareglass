# Synthetic demo files

Every file in this directory was generated specifically for ShareGlass. They contain fictional names, domains under `.example` or `.test`, and intentionally risky structures so the live demo can be used safely.

- `private-photo.png`: EXIF GPS, author, software, timestamp, and text chunks.
- `private-resume.docx`: authors, comments, tracked revisions, a hidden paragraph, custom XML, a cached thumbnail, and external relationships.
- `risky-contract.pdf`: metadata, JavaScript OpenAction, an external URI, an embedded text file, and an AcroForm dictionary.

Do not replace these fixtures with real personal or company documents.
